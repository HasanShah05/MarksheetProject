# Marksheet Project

A full-stack web application for creating and managing student marksheets — built with a Vite-powered frontend and a Node.js backend.

*(Update this one-liner with the exact purpose — e.g. "Lets teachers enter student grades and auto-generates a formatted marksheet.")*

## ✨ Features

- Add/manage student records and marks
- Client-server architecture with a dedicated backend API

## 🛠️ Tech Stack

**Frontend:** JavaScript, Vite, HTML/CSS
**Backend:** Node.js (see `/backend`)
**Tooling:** ESLint

## 📁 Project Structure

```
MarksheetProject/
├── backend/        # Server-side API and logic
├── src/            # Frontend source code
├── index.html      # App entry point
├── vite.config.js  # Vite build configuration
└── eslint.config.js
```

## 🚀 Getting Started

```bash
git clone https://github.com/HasanShah05/MarksheetProject.git
cd MarksheetProject

# Install frontend dependencies
npm install

# Run the frontend dev server
npm run dev

# In a separate terminal, set up the backend
cd backend
npm install
npm start
```
